# Project Guidelines

## Code Style
- Respect the formatting rules based on wp-scripts
- Follow the patterns in ./docs
- Keep code concise. Do not over architect.

## Documentation
- Do not add new documentation
- If documentation is out of date propose an update

## CSS
- Prefer class names over targeting HTML elements
- Target HTML elements if the element is auto generated by a Wordpress hook

## Testing
- Follow existing testing patterns
- Do not add tests by default. Propose any new tests.
